EEG TRAINER DATA COLLECTION SYSTEM - TECHNICAL SPECIFICATIONS
================================================================================

SYSTEM OVERVIEW:
--------------------------------------------------------------------------------
Device: Muse S Athena (EEG/fNIRS headband)
Protocol: OSC (Open Sound Control) over UDP
Port: 8052
Sample Rate: 256 Hz (target)
Parser: Custom OSC parser (manual binary parsing)

DATA CHANNELS:
--------------------------------------------------------------------------------
EEG: 4 channels (TP9, AF7, AF8, TP10)
  - Temporal and frontal electrode positions
  - High-pass filtered (moving average baseline removal)
  - Units: microvolts (uV)

fNIRS/Optics: 8 channels total
  - 4 normalized channels (Ch1-4_norm)
  - 4 raw channels (Ch1-4_raw)
  - Measures blood oxygenation changes

Motion: 6-DOF inertial measurement
  - 3 accelerometer axes (acc_x, acc_y, acc_z)
  - 3 gyroscope axes (gyro_x, gyro_y, gyro_z)

Reference: 2 channels (DRL, REF)
  - Ground and reference electrode signals

LABELING METHODOLOGY:
--------------------------------------------------------------------------------
Mode Toggle: 'C' key switches between READING and LABELING modes
  - Reading mode: Data collection active, cursor tracking enabled
  - Labeling mode: Data collection PAUSED, confusion marking enabled

Confusion Marking:
  - LEFT-DRAG: Select multi-word phrases for 'word_confusion' label
  - RIGHT-CLICK: Mark entire sentence for 'sentence_confusion' label
  - Cursor tracking: Continuous word-under-cursor recording (50ms update)

Data Pausing:
  - When entering labeling mode, EEG/fNIRS recording PAUSES
  - This prevents contamination of baseline data with labeling artifacts
  - Recording resumes when returning to reading mode

NPZ FILE STRUCTURE:
--------------------------------------------------------------------------------
11 Arrays stored per session:
  1. timestamps: Absolute Unix timestamps (float64)
  2. relative_timestamps: Time relative to session start (float64)
  3. eeg: EEG data [N_samples x 4] (float32)
  4. fnirs: fNIRS data [N_samples x 8] (float32)
  5. motion: Motion data [N_samples x 6] (float32)
  6. ref: Reference data [N_samples x 2] (float32)
  7. event_timestamps: Confusion event times (float64)
  8. event_types: Event type strings ('word_confusion' or 'sentence_confusion')
  9. event_words: Text that was marked as confusing (object dtype)
 10. words: Word at each sample timepoint (object dtype)
 11. metadata: Dict with recording parameters (dict)

SYNCHRONIZATION:
--------------------------------------------------------------------------------
EEG packets drive the timeline (256 Hz master clock)
fNIRS and motion data interpolated to match EEG timestamps
Last-value interpolation fills gaps between non-EEG packets
NaN values indicate missing data for interpolated channels
